# AgentUsage 0.4.2

This release makes the menu-bar configuration clearer and safer when only one provider is enabled.

## What changed

- Keeps Codex, Claude, and Both visible in the menu provider selector while disabling unavailable choices.
- Prevents unavailable provider selections from being applied outside the UI.
- Adds native SwiftUI movement animation when changing segmented controls and honors Reduce Motion.
- Uses stable `5h%` and `7d%` metric labels instead of labels that change with the current data.

## Updating

If AgentUsage 0.4.1 is installed, choose **Check for Updates** at the bottom of the popout to download and install this release.

> [!WARNING]
> This build is ad-hoc signed, not Apple Developer ID-signed or notarized. The first launch may require **Open Anyway** in System Settings → Privacy & Security.
