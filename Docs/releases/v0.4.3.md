# AgentUsage 0.4.3

Claude authorization now persists across app updates.

- Adds a minimal Claude usage helper authorized once and preserved across updates.
- Keeps OAuth tokens inside the helper while returning plan and raw usage data to the app.
- Remembers chart positions and simplifies provider controls with availability-aware defaults.
- Adds Homebrew installation through `Rock-Z/tap`.
- Simplifies the one-click installer and strengthens release verification.

> [!WARNING]
> AgentUsage remains self-signed and is not Apple-notarized. macOS may block the first launch after installing from the DMG; use **Open Anyway** in **System Settings → Privacy & Security**.
