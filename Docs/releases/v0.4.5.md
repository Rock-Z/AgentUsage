# AgentUsage 0.4.5

AgentUsage is easier to launch and configure, with a more compact menu and targeted Codex recovery.

- Starts unobtrusively at login and opens its menu when explicitly reopened.
- Adds an **Open on Startup** switch using macOS Login Items.
- Collapses settings into a remembered **Options** section.
- Refreshes the interface with clearer light and dark accent colors.
- Keeps Claude usage available after OAuth refreshes without repeated Keychain authorization.
- Recovers from the known Codex startup credential timeout and retries, without hiding unrelated errors.
