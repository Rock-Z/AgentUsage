# AgentUsage 0.5.0

AgentUsage shows every limit your providers report and gets a simpler, native-feeling popover.

- Shows one bar per limit reported by Codex and Claude, named from the provider's own data, so new limits such as model-specific weekly allowances appear automatically.
- Shows plan names as providers market them, such as Pro 20x and Max 5x, read from live account data.
- Lets the menu bar show limits and credits independently. Limits appear as nested 5-hour and 7-day rings, or the 7-day ring alone when there is no 5-hour window.
- Shows credit balances even when they are zero.
- Pins providers to the menu bar, refreshes them, and turns them off from icons in each card header. A turned-off provider collapses to one line.
- Replaces the options panel with compact rows of native switches that animate open and closed.
- Uses the macOS Liquid Glass appearance and improves text contrast over any wallpaper.
- Makes fewer requests: the Claude plan is read at most hourly, and Codex reset expirations come from the Codex app instead of a separate web request.
