# AgentUsage 0.6.0

AgentUsage lets you choose its accent color and reads better on any menu bar.

- Adds an accent color to Options. It follows the macOS accent by default; turn off System to pick a preset or drag across a color pad, with a slider for darker or lighter tones. Each change can be undone with Command-Z.
- Draws the menu bar icon like other menu bar icons, so it stays legible on light, dark, and tinted menu bars and on inactive displays.
- Remembers which providers are pinned to the menu bar when one is turned off and back on.
- Shows plans exactly as Codex and Claude report them, so renamed or new plans appear without an update.
- Scrolls the weekly chart in whole bars and animates the options panel as it folds open and closed.
